# Registro de Feedback Interno (Agente)

Este archivo consolida las lecciones aprendidas sobre tono y estilo para que el agente las aplique en futuros textos.

## Recomendaciones de Estilo (Consolidado)

### Título SEO: Conflicto "Artesanía vs Automatización"
- **Crítica:** "Artesanía" sola suena lenta.
- **Solución:** Usar **"Artesanía de Software y Eficiencia Operativa"**.

### Tono Agresivo (Meta Descripción)
- **Crítica:** "No vendemos humo" es defensivo.
- **Solución:** Usar **"Rigor técnico y honestidad profesional"**.

### Conexión Semántica
- **Crítica:** Servicios backend e integración desconectados.
- **Solución:** "Unificamos arquitectura backend e integración de sistemas".

### Profundidad Técnica vs. Agilidad
- **Crítica:** Evitar sonar académico o lento.
- **Solución:** "Aportamos la profundidad técnica necesaria para identificar la **solución más viable**".

### Idioma: Zero Spanglish
- **Crítica:** Anglicismos de negocio (*commodity, partnership, skin in the game*) restan seriedad.
- **Solución:** Traducir a conceptos equivalentes (*Producto básico, Alianza, Compartimos riesgo*). Mantener solo nombres técnicos (BigQuery, dbt).
