# Tracked files the citability scan cannot read, each with the reason it is
# allowed to stay that way (#324).
#
# `grep -I` skips a file the moment it sees a NUL byte, and says nothing. That
# is 125 of this repository's 414 tracked files — about 30 MB of a PUBLIC tree
# sitting outside the only gate that checks who gets named. A guard that skips
# in silence and a tree that is clean produce the same green.
#
# So the scan now does three things instead of one: it reads what it can
# extract (OOXML documents), it refuses the rest unless the reason is written
# down here, and it fails on anything opaque that nobody has accounted for.
#
# Format: one glob per line, then `#` and the reason. Matching is `fnmatch`, so
# `*` crosses `/` — a rule is a SUBTREE assertion, not a single directory level.
# That is deliberate (a nested folder of the same material stays accounted for),
# and it is stated here because a glob that is broader than it looks is the kind
# of thing this file exists to stop. The reason is
# the point — "binary" is not a reason, it is a restatement of the problem.
# Adding a line is a deliberate act: you are asserting this file carries no
# text that the naming policy (§13) applies to.
